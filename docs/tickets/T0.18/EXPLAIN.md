# T0.18: Flight engine skeleton and live WebSocket

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- A flight engine service reads the MAVLink 2 telemetry of the simulated Drones of each Mission and, every 50 ms, builds one `SquadFrame` per Mission.
- Each frame goes first to the engine's local WebSocket (the edge `/v1/live`), then to the leaf node on NATS, so the cell and the gateway can carry it on.
- The gateway serves `/v1/live`: a client proves who it is with its token, subscribes to a Mission of its own Operator and receives the frames in MessagePack.
- A slow client never builds up a queue: it keeps one slot and skips the frames it did not read.
- CI can now run the live path: it installs the pinned nats-server and builds the `swarm_core` wheel where needed.

## ⚙️ How it works

1. **Decode in Rust:** a datagram becomes frames in [`decode`](../../../rust/swarm-core/mavlink/src/frame.rs#L101), which never panics on bad bytes and counts them as rejected; [`parse_v2`](../../../rust/swarm-core/mavlink/src/frame.rs#L152) reads one MAVLink 2 frame.
2. **Keep the latest sample per Drone:** [`LatestFrames::ingest`](../../../rust/swarm-core/mavlink/src/latest_frames.rs#L95) folds the frames in and [`snapshot`](../../../rust/swarm-core/mavlink/src/latest_frames.rs#L107) returns one `DroneSample` per Drone.
3. **Expose it to Python without the GIL:** the wheel's [`ingest`](../../../rust/swarm-core/python/src/lib.rs#L111) detaches from the interpreter while it decodes.
4. **Listen on UDP:** [`MavlinkListener.ingest`](../../../backend/swarm-clients/src/swarm_clients/flight/mavlink/mavlink_listener.py#L73) stamps each datagram with its arrival time and gives it to the Rust store.
5. **Start the process:** [`serve_command.py`](https://github.com/gpbcom/swarm/blob/a2e43f7e74d65cc12a43507ec33f673fd2bc62e3/services/flight-engine/src/flight_engine/api/cli/commands/serve_command.py#L138) runs the engine and the local live server on uvloop; [`FlightEngine.initialize`](../../../backend/swarm-service/src/swarm_service/flight/engine/flight_engine.py#L100) starts one `MissionActor` per Mission of the catalogue.
6. **Tick every 50 ms:** [`MissionActor.run`](../../../backend/swarm-service/src/swarm_service/flight/missions/mission_actor.py#L114) keeps a monotonic schedule and skips missed slots instead of running a burst.
7. **Build and publish one frame:** [`_tick`](../../../backend/swarm-service/src/swarm_service/flight/missions/mission_actor.py#L90) snapshots the samples, builds the `SquadFrame` with [`SquadFrameBuilder.build`](../../../backend/swarm-service/src/swarm_service/flight/missions/squad_frame_builder.py#L169), encodes it, publishes it to the local hub, then to the leaf node through [`SquadFramePublisher.publish`](../../../backend/swarm-clients/src/swarm_clients/flight/leaf/squad_frame_publisher.py#L46). A leaf failure is logged and the ticks go on.
8. **Fan out locally:** [`LiveHub.publish`](../../../backend/swarm-service/src/swarm_service/shared/live/hub/live_hub.py#L78) puts the bytes in the one-slot mailbox of every watcher; [`LiveMailbox.put`](../../../backend/swarm-service/src/swarm_service/shared/live/hub/live_mailbox.py#L40) replaces an unread frame and counts it as skipped.
9. **Serve the client:** [`LiveSession.run`](../../../backend/swarm-service/src/swarm_service/shared/live/live_session.py#L118) reads subscribe messages; [`_subscribe`](../../../backend/swarm-service/src/swarm_service/shared/live/live_session.py#L91) decodes one, joins the topic and starts a sender task for its mailbox. The edge socket is [`LiveEndpoint`](https://github.com/gpbcom/swarm/blob/a2e43f7e74d65cc12a43507ec33f673fd2bc62e3/services/flight-engine/src/flight_engine/api/live/live_endpoint.py#L57).
10. **Gateway: identity first:** [`LiveOperator.__call__`](../../../backend/swarm-api/src/swarm_api/dependencies/live_operator.py#L71) verifies the token with T0.11's access service and answers 1008 when there is no Operator; [`LiveRouter._serve`](../../../backend/swarm-api/src/swarm_api/v1/live/live_router.py#L55) takes the Operator from it and never from the message.
11. **Gateway: one NATS subscription per subject:** [`LiveFanOut.join`](../../../backend/swarm-service/src/swarm_service/gateway/live/live_fan_out.py#L95) builds the subject from the connection's Operator ([`_subject`](../../../backend/swarm-service/src/swarm_service/gateway/live/live_fan_out.py#L50)) and subscribes to NATS only for the first watcher; [`leave`](../../../backend/swarm-service/src/swarm_service/gateway/live/live_fan_out.py#L122) unsubscribes on the last.
12. **Wiring:** [`gateway_rest_app.py`](https://github.com/gpbcom/swarm/blob/a2e43f7e74d65cc12a43507ec33f673fd2bc62e3/services/gateway/src/gateway/api/rest/gateway_rest_app.py#L60) creates the feed, includes the live router and installs the feed's lifespan.
