# T0.10: Images, scans, signatures and Playwright

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- Builds one multi-stage image per changed service or front end that has a Dockerfile, from the repository root.
- Scans the lock files and each image, writes an SBOM, pushes to GHCR, then signs and attests the image without a key.
- Runs Playwright against the real images started by [`compose.e2e.yaml`](../../../compose.e2e.yaml), never a development server, and uploads its HTML report when it fails.
- Tags an image with the commit SHA only on pushes to `develop` or `master`.
- Makes the dev cell refuse an unsigned Swarm image.

## ⚙️ How it works

1. **Select the images:** `discover_images` lists every `services/<x>` and `frontends/<x>` folder with a Dockerfile, [`.github/scripts/detect_changes.py:71-81`](../../../.github/scripts/detect_changes.py#L71-L81). The script prints it as a sixth output, [`.github/scripts/detect_changes.py:173`](../../../.github/scripts/detect_changes.py#L173). `images.yml`, [`compose.e2e.yaml`](../../../compose.e2e.yaml) and [`.dockerignore`](../../../.dockerignore) are shared files and select everything, [`.github/scripts/detect_changes.py:36-44`](../../../.github/scripts/detect_changes.py#L36-L44).
2. **Gate on the earlier checks:** the `images` job of CI waits for every language check and specs, and is skipped when the list is empty, [`.github/workflows/ci.yml:88-98`](../../../.github/workflows/ci.yml#L88-L98). `publish` is true only for a push to `develop` or `master`, [`.github/workflows/ci.yml:98`](../../../.github/workflows/ci.yml#L98).
3. **Scan dependencies:** OSV-Scanner reads the three lock files, [`.github/workflows/images.yml:25`](../../../.github/workflows/images.yml#L25).
4. **Build, scan, push:** one matrix job per image, [`.github/workflows/images.yml:37`](../../../.github/workflows/images.yml#L37). It builds with the gha cache, runs Trivy ([line 82](../../../.github/workflows/images.yml#L82)), writes the CycloneDX SBOM ([line 86](../../../.github/workflows/images.yml#L86)), pushes the run tag and reads the digest back ([line 95](../../../.github/workflows/images.yml#L95)).
5. **Sign and verify:** keyless cosign signature ([line 103](../../../.github/workflows/images.yml#L103)), SBOM attestation ([line 105](../../../.github/workflows/images.yml#L105)) and a verify by digest ([line 107](../../../.github/workflows/images.yml#L107)).
6. **Run the images:** the `e2e` job pulls the run-tag images ([line 153](../../../.github/workflows/images.yml#L153)), runs Playwright ([line 166](../../../.github/workflows/images.yml#L166)) and keeps the report ([line 168](../../../.github/workflows/images.yml#L168)). The stack comes from [`compose.e2e.yaml:1-7`](../../../compose.e2e.yaml#L1-L7), which needs `SWARM_IMAGE_TAG`. `defineE2eConfig` refuses a `webServer`, [`packages/ts/e2e/src/define-e2e-config.ts:22`](../../../packages/ts/e2e/src/define-e2e-config.ts#L22), and writes the html reporter, [`packages/ts/e2e/src/define-e2e-config.ts:33`](../../../packages/ts/e2e/src/define-e2e-config.ts#L33).
7. **Publish:** the `publish` job adds the commit SHA tag to the same signed digest ([line 202](../../../.github/workflows/images.yml#L202)) and verifies it ([line 210](../../../.github/workflows/images.yml#L210)), [`.github/workflows/images.yml:178`](../../../.github/workflows/images.yml#L178).
8. **Admit only signed images:** the policy-controller is deployed by Argo CD, [`deploy/environments/dev/platform/policy-controller.yaml:1`](../../../deploy/environments/dev/platform/policy-controller.yaml#L1). The ClusterImagePolicy enforces keyless signatures on `ghcr.io/gpbcom/swarm/**`, [`deploy/environments/dev/platform/cluster-image-policy.yaml:9-17`](../../../deploy/environments/dev/platform/cluster-image-policy.yaml#L9-L17). The cell namespace opts in with a label, [`deploy/terraform/modules/self-hosted/cell/main.tf:8`](../../../deploy/terraform/modules/self-hosted/cell/main.tf#L8).
9. **Probe at the end of `up`:** a server-side dry run of an unsigned image must fail, [`deploy/scripts/dev-cell.sh:106-118`](../../../deploy/scripts/dev-cell.sh#L106-L118), called at [`deploy/scripts/dev-cell.sh:125`](../../../deploy/scripts/dev-cell.sh#L125).
10. **The gateway image:** two stages, pinned bases, uid 10001, `swarm-gateway` entrypoint, [`services/gateway/Dockerfile:4`](../../../services/gateway/Dockerfile#L4), [`services/gateway/Dockerfile:33`](../../../services/gateway/Dockerfile#L33), [`services/gateway/Dockerfile:46-48`](../../../services/gateway/Dockerfile#L46-L48).
