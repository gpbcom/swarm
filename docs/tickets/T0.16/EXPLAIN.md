# T0.16: Create an Operator (UC-029)

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- The Swarm administrator creates an Operator in the Back office: name, deployment, Jurisdictions, LLM provider and Anchoring, then the first Mission planner.
- The gateway stores the Operator, its cell assignment and the planner in its own PostgreSQL schema, creates the Keycloak organisation and invites the planner by e-mail, and undoes Keycloak if the database step fails.
- A name already taken (A1) and a missing field (A2) are refused, and the screen says which.
- The directory is listed in the Back office, and one Operator is read back only by the roles allowed to see it.

## ⚙️ How it works

1. **Sign-in and gateway client:** the Back office signs the administrator in and builds a typed gateway client, in [`frontend/apps/back-office/src/auth/oidc.ts`](../../../frontend/apps/back-office/src/auth/oidc.ts) and [`frontend/apps/back-office/src/api/gateway.ts`](../../../frontend/apps/back-office/src/api/gateway.ts).
2. **Entry step:** the draft holds a null LLM provider until the person chooses, and `effectiveProvider` derives the default from the deployment, in [`frontend/apps/back-office/src/operators/entry-checks.ts:29`](../../../frontend/apps/back-office/src/operators/entry-checks.ts#L29). The first check (name required, name taken against the listed directory) is `checkEntry` at [`frontend/apps/back-office/src/operators/entry-checks.ts:60`](../../../frontend/apps/back-office/src/operators/entry-checks.ts#L60).
3. **Submit:** `POST /v1/operators` carries the provider in effect, in the mutation at [`frontend/apps/back-office/src/operators/OperatorsScreen.tsx:75`](../../../frontend/apps/back-office/src/operators/OperatorsScreen.tsx#L75).
4. **Route:** the router declares the create, list and read routes, each behind a `RouteAccess`, in [`backend/swarm-api/src/swarm_api/v1/gateway/operator_router.py:86`](../../../backend/swarm-api/src/swarm_api/v1/gateway/operator_router.py#L86), and the gateway router wires the service and its lifespan at [`backend/swarm-api/src/swarm_api/v1/gateway/gateway_router.py:69`](../../../backend/swarm-api/src/swarm_api/v1/gateway/gateway_router.py#L69).
5. **Entry checks:** the service refuses a missing field and normalises the name, in [`backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py:125`](../../../backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py#L125).
6. **Create in one transaction:** `create` opens a unit of work scoped to the new Operator, refuses a taken name (also when the unique index fires), adds the Operator, its cell assignment and the person, then invites in Keycloak, in [`backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py:248`](../../../backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py#L248).
7. **Keycloak:** the admin client creates the organisation and invites the planner, in [`backend/swarm-clients/src/swarm_clients/gateway/keycloak/keycloak_admin_client.py:273`](../../../backend/swarm-clients/src/swarm_clients/gateway/keycloak/keycloak_admin_client.py#L273) and [`backend/swarm-clients/src/swarm_clients/gateway/keycloak/keycloak_admin_client.py:296`](../../../backend/swarm-clients/src/swarm_clients/gateway/keycloak/keycloak_admin_client.py#L296). If the transaction fails afterwards, `_remove_from_keycloak` deletes both ([`backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py:190`](../../../backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py#L190)).
8. **Storage:** the tables come from [`backend/swarm-storage/src/swarm_storage/gateway/ddl/operator_directory_tables.py:84`](../../../backend/swarm-storage/src/swarm_storage/gateway/ddl/operator_directory_tables.py#L84), applied by the migration [`backend/apps/gateway/migrations/versions/0002_create_operator_directory.py:16`](../../../backend/apps/gateway/migrations/versions/0002_create_operator_directory.py#L16); each entity has one repository, for example [`backend/swarm-storage/src/swarm_storage/gateway/operators/operator_repository.py:89`](../../../backend/swarm-storage/src/swarm_storage/gateway/operators/operator_repository.py#L89).
9. **Answer and conflicts:** a 409 reaches the screen. It reads the directory again: a listed name goes back to the entry step with A1, otherwise the planner step shows the e-mail error, in [`frontend/apps/back-office/src/operators/OperatorsScreen.tsx:83`](../../../frontend/apps/back-office/src/operators/OperatorsScreen.tsx#L83) and [`frontend/apps/back-office/src/operators/FirstMissionPlannerStep.tsx:114`](../../../frontend/apps/back-office/src/operators/FirstMissionPlannerStep.tsx#L114).
10. **List and read:** the directory page and one Operator are read by [`backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py:299`](../../../backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py#L299) and [`backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py:322`](../../../backend/swarm-service/src/swarm_service/gateway/operators/operator_service.py#L322); the isolation test with two Operators is [`tests/swarm_api/v1/gateway/operator_router/test_gateway_operator_isolation.py`](../../../tests/swarm_api/v1/gateway/operator_router/test_gateway_operator_isolation.py).
