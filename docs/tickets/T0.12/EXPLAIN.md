# T0.12: Service skeletons with row-level security

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- Three services, gateway, missions and fleet, follow the AGENT.md layers, each with its own PostgreSQL schema, its Alembic migrations and an outbox table.
- Row-level security on `operator_id` is forced on that table: a query that forgets the Operator returns nothing.
- Every service answers on `/v1` with `problem+json` errors, an `Idempotency-Key` check on POST and `ETag` / `If-Match` helpers, and publishes its OpenAPI document.
- The TypeScript client of `packages/ts/api-client` is generated from those documents and checked in CI.
- Each service has one non-root image that finds its `conf/` and `migrations/` through `SWARM_<SERVICE>_HOME`.

## ⚙️ How it works

1. **Migrations create the table:** the first revision runs the outbox DDL for the service schema, in [`services/gateway/migrations/versions/0001_create_outbox.py:14-22`](../../../services/gateway/migrations/versions/0001_create_outbox.py#L14-L22). The same shape is in missions and fleet.
2. **The outbox table is built:** [`packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/outbox_table.py:52`](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/outbox_table.py#L52) returns the statements, with an `operator_id uuid NOT NULL` column ([line 30](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/outbox_table.py#L30)) and an index on `(operator_id, id)` ([line 36](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/outbox_table.py#L36)).
3. **Row-level security is added:** [`packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/row_level_security.py:102`](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/row_level_security.py#L102) enables it, forces it on the table owner ([line 41](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/row_level_security.py#L41)) and creates a policy comparing `operator_id` with `NULLIF(current_setting('swarm.operator_id', true), '')::uuid` ([lines 43-45](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/ddl/row_level_security.py#L43-L45)). An unset setting is NULL, so it matches no row.
4. **The migrator applies them:** [`packages/python/swarm-storage/src/swarm_storage/storage/postgres/migrations/alembic_migrator.py:181`](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/migrations/alembic_migrator.py#L181) upgrades the schema, called from each service's schema service.
5. **A unit of work sets the Operator:** [`packages/python/swarm-storage/src/swarm_storage/storage/postgres/postgres_pool.py:98`](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/postgres_pool.py#L98) hands out a unit of work, which runs `set_config('swarm.operator_id', ..., true)` for the transaction only, and nothing when there is no Operator ([`packages/python/swarm-storage/src/swarm_storage/storage/postgres/unit_of_work.py:88-89`](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/unit_of_work.py#L88-L89)).
6. **Repositories add no Operator filter:** [`packages/python/swarm-storage/src/swarm_storage/storage/postgres/repositories/postgres_repository.py:205`](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/repositories/postgres_repository.py#L205) lists rows and relies on the policy. A write the policy refuses becomes `SEStorageOperatorRefusedError` ([line 186](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/repositories/postgres_repository.py#L186), [line 267](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/repositories/postgres_repository.py#L267)). The outbox reads pending events in [`packages/python/swarm-storage/src/swarm_storage/storage/postgres/repositories/outbox_repository.py:77`](../../../packages/python/swarm-storage/src/swarm_storage/storage/postgres/repositories/outbox_repository.py#L77).
7. **Each service builds its REST app:** [`services/gateway/src/gateway/api/rest/gateway_rest_app.py:48`](../../../services/gateway/src/gateway/api/rest/gateway_rest_app.py#L48) calls [`packages/python/swarm-rest/src/swarm_rest/api/rest/rest_app_builder.py:128`](../../../packages/python/swarm-rest/src/swarm_rest/api/rest/rest_app_builder.py#L128), which installs the problem handlers ([`problem_handlers.py:83`](../../../packages/python/swarm-rest/src/swarm_rest/api/rest/problem_handlers.py#L83)), the pure-ASGI idempotency middleware ([`idempotency_middleware.py:214`](../../../packages/python/swarm-rest/src/swarm_rest/api/rest/idempotency_middleware.py#L214)) and the document at `/v1/openapi.json`. `ETag` checks are in [`entity_tag.py:55`](../../../packages/python/swarm-rest/src/swarm_rest/api/rest/entity_tag.py#L55).
8. **The OpenAPI document is exported:** [`packages/python/swarm-rest/src/swarm_rest/api/cli/openapi_export_command.py:70`](../../../packages/python/swarm-rest/src/swarm_rest/api/cli/openapi_export_command.py#L70) writes it to `packages/ts/api-client/openapi/`, or with `check` compares it. Each service's pytest also compares it ([gateway](../../../services/gateway/tests/api/rest/test_gateway_rest_app.py#L59), [missions](../../../services/missions/tests/api/rest/test_missions_rest_app.py#L55), [fleet](../../../services/fleet/tests/api/rest/test_fleet_rest_app.py#L66)).
9. **The client is generated and checked:** [`packages/ts/api-client/scripts/generate.ts:33-58`](../../../packages/ts/api-client/scripts/generate.ts#L33-L58) renders the client from each document and, with `--check`, fails when a generated file differs.
10. **The image finds its folders:** [`services/gateway/Dockerfile:37-39`](../../../services/gateway/Dockerfile#L37-L39) sets `SWARM_GATEWAY_HOME=/app` and copies `conf/` and `migrations/` there. [`gateway_config.py:153-163`](../../../services/gateway/src/gateway/models/config/gateway_config.py#L153-L163) returns that folder when set, and `migrations_folder()` ([line 175](../../../services/gateway/src/gateway/models/config/gateway_config.py#L175)) builds on it. The schema service factory uses it ([`schema_service_factory.py:36-43`](../../../services/gateway/src/gateway/service/factories/schema_service_factory.py#L36-L43)).
