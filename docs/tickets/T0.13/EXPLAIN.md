# T0.13: Simulator base

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- A new Simulator service flies a simulated Squad (10 synthetic Drones and one PX4 SITL Drone) on a square route with `swarm-simulator fly`.
- `swarm-simulator serve` answers Commands on NATS, and only with credentials tagged `simulated`.
- A Command to a Drone outside the adapter registry is refused and logged, and every Flight log entry is marked simulated.
- A Rust crate runs up to 255 synthetic MAVLink 2 Drones per process, and a container image runs PX4 SITL with headless Gazebo.
- A `simulator` Helm sub-chart, off by default, deploys them in a cell.

## ⚙️ How it works

1. **Entry point:** `main` builds a `ServeCommand` or a `FlyCommand` through its factory, in [`services/simulator/src/simulator/api/cli/main.py:47`](../../../services/simulator/src/simulator/api/cli/main.py#L47) and [`main.py:54`](../../../services/simulator/src/simulator/api/cli/main.py#L54).
2. **Configuration:** the deployment values (Operator, credentials path, responder subject) have no default. `validate_deployment` refuses a subject outside `op.<operator_id>.` in [`simulator_config.py:154`](../../../services/simulator/src/simulator/models/config/simulator_config.py#L154). The shipped defaults are in [`conf/app.yaml`](../../../services/simulator/conf/app.yaml).
3. **Credentials guard (serve):** `initialize` refuses with no credentials file, then runs the guard, before any connection, in [`serve_command.py:143`](../../../services/simulator/src/simulator/api/cli/commands/serve_command.py#L143). The guard decodes the JWT payload and requires the `simulated` tag in [`simulated_credentials_guard.py:149`](../../../services/simulator/src/simulator/service/credentials/simulated_credentials_guard.py#L149).
4. **Serving:** `_serve` connects to NATS and drives the responder in [`serve_command.py:119`](../../../services/simulator/src/simulator/api/cli/commands/serve_command.py#L119). The endpoint is [`command_endpoint.py`](../../../services/simulator/src/simulator/api/bus/command_endpoint.py).
5. **Adapter registry:** the catalogue of the simulated Squad is loaded, and `register` refuses a host outside `simulated_hosts` and a duplicate Drone, in [`adapter_registry.py:47`](../../../services/simulator/src/simulator/service/registry/adapter_registry.py#L47).
6. **Command handling:** `handle` resolves the target through the registry only. An unknown Drone, or a kind with no mapping, is logged at WARNING and answered `REFUSED`; otherwise each Drone is sent the MAVLink command, in [`simulated_command_service.py:188`](../../../services/simulator/src/simulator/service/commands/simulated_command_service.py#L188).
7. **Flight (fly):** `FlyCommand.run` flies the Squad and prints one line per outcome, with an exit code, in [`fly_command.py:72`](../../../services/simulator/src/simulator/api/cli/commands/fly_command.py#L72). `SquadFlight` runs one `DroneFlight` per Drone ([`squad_flight.py:55`](../../../services/simulator/src/simulator/service/flights/squad_flight.py#L55)) and `all_completed` decides success ([`squad_flight.py:72`](../../../services/simulator/src/simulator/service/flights/squad_flight.py#L72)).
8. **One Drone's flight:** position, upload of the square route, arm, start, then one step per waypoint reached, in [`drone_flight.py:137`](../../../services/simulator/src/simulator/service/flights/drone_flight.py#L137). The MAVLink calls are in [`mavlink_drone_client.py:279`](../../../services/simulator/src/simulator/clients/mavlink/mavlink_drone_client.py#L279) (connect) to [`:412`](../../../services/simulator/src/simulator/clients/mavlink/mavlink_drone_client.py#L412) (send a command), and the client takes host and port from the `RegisteredDrone` only.
9. **Flight log:** each step is a `FlightLogEntry`, whose `simulated` field defaults to true and is validated in [`flight_log_entry.py:184`](../../../services/simulator/src/simulator/models/flight_logs/flight_log_entry.py#L184). `append` refuses an entry not simulated ([`flight_log_store.py:115`](../../../services/simulator/src/simulator/storage/edge/flight_log_store.py#L115)) and the SQLite table has `CHECK (simulated = 1)` ([`flight_log_store.py:43`](../../../services/simulator/src/simulator/storage/edge/flight_log_store.py#L43)).
10. **Synthetic Drones (Rust):** a `Fleet` of up to 255 Drones ([`link.rs:29`](../../../packages/rust/swarm-synthetic-drones/src/link.rs#L29), [`link.rs:73`](../../../packages/rust/swarm-synthetic-drones/src/link.rs#L73)) runs on one thread. `run` ticks forever ([`link.rs:361`](../../../packages/rust/swarm-synthetic-drones/src/link.rs#L361)); each `step` reads at most 64 datagrams per Drone ([`link.rs:66`](../../../packages/rust/swarm-synthetic-drones/src/link.rs#L66), [`link.rs:346`](../../../packages/rust/swarm-synthetic-drones/src/link.rs#L346)). A Drone answers MAVLink messages in [`drone.rs:158`](../../../packages/rust/swarm-synthetic-drones/src/drone.rs#L158) and moves in [`drone.rs:178`](../../../packages/rust/swarm-synthetic-drones/src/drone.rs#L178), following its route with [`route.rs:74`](../../../packages/rust/swarm-synthetic-drones/src/route.rs#L74). The `step` benchmark is [`step.rs:22`](../../../packages/rust/swarm-synthetic-drones/benches/step.rs#L22).
11. **PX4 SITL image:** built with `HEADLESS=1 make px4_sitl_default` ([`Dockerfile:17`](../../../deploy/images/px4-sitl/Dockerfile#L17)) and started by [`entrypoint.sh`](../../../deploy/images/px4-sitl/entrypoint.sh).
12. **Deployment:** the `simulator` chart runs the service, the synthetic Drones and PX4 SITL ([`values.yaml`](../../../deploy/charts/simulator/values.yaml)); its NetworkPolicy lets only the simulator pod reach the Drone pods ([`networkpolicy.yaml:1-21`](../../../deploy/charts/simulator/templates/networkpolicy.yaml#L1-L21)). The cell chart holds it as an optional dependency ([`Chart.yaml:24-26`](../../../deploy/charts/cell/Chart.yaml#L24-L26)), off in [`values.yaml:14-15`](../../../deploy/charts/cell/values.yaml#L14-L15).

## 🧪 How to test it

```bash
uv run pytest tests/simulator -rs
uv run pytest services/simulator/tests -n 2
cd packages/rust && cargo test -p swarm-synthetic-drones && cargo bench -p swarm-synthetic-drones --bench step
docker build -f deploy/images/px4-sitl/Dockerfile -t swarm-px4-sitl:local .
uv run pytest tests/simulator -rs
```

The first run skips the PX4 test; the last one, after the image build, runs it.
